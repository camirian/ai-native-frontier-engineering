# Contributing

Contributions should extend the clean-room method, not inflate claims.

Before proposing a new experiment, provide a frozen specification, independent oracle, candidate-generation record, held-out plan, falsification controls, reproduction command, and a claim boundary. Do not submit proprietary data, credentials, personal data, or third-party code without a compatible license.

Every result must distinguish design-set evidence from held-out evidence. A candidate that wins only on its design envelope is not a robust winner.
