# SYS-PROTOCOL-001 public evidence package

This directory distributes the complete sanitized SYS-PROTOCOL-001 evidence bundle as `sys-protocol-001-evidence.tar.gz`. The archive contains the frozen requirements, three candidate implementations, independent oracle, design and held-out traces, mutation results, traceability, impact analysis, claim boundary, and reproduction script.

Verify `SHA256SUMS.txt`, extract the archive into a disposable directory, and run `sys-protocol-001/reproduce.sh` from the extracted directory. The archive contains no local absolute paths, credentials, proprietary requirements, or external protocol specification.
