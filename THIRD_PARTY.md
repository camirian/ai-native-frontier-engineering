# Third-party inventory

All Python source, JSON/CSV data, Markdown documentation, and deterministic SVG media in this package were authored for the two clean-room experiments or generated from their packaged data.

The only runtime dependency is NumPy, specified in `requirements.txt`. NumPy is not copied into this repository and remains subject to its own license.

No third-party source code, assets, datasets, or media are redistributed in this package.
